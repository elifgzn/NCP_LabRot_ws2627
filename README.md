# Photo Shooting Experiment

This repository contains the experimental code, stimuli, background literature, and course documents for the **Photo Shooting Experiment**, conducted by LMU-NCP students as part of their Lab Rotation during the Winter Semester 2026/27.

## Repository Structure

```
.
├── experiment/
│   ├── README.md
│   ├── CARA_B_main_trialwise.py
│   ├── CODE_GUIDE.md
│   └── chosen_stimuli_nolures/
├── papers/
│   ├── guide_to_papers.md
│   └── *.pdf
├── NCP Lab Rotation Project Evaluation WS_2026-27.docx
├── Photo Shooting Study Data Analysis Plan.pdf
├── PreregistrationTemplate.docx
├── Schedule_LabRotation_BoSCAGroup.docx
└── README.md
```

| Path | Description |
|------|-------------|
| [`experiment/`](experiment/README.md) | The experimental code and stimuli. See the folder's README for how to run the experiment. |
| [`papers/`](papers/guide_to_papers.md) | Background literature. See `guide_to_papers.md` for an overview. |
| `Schedule_LabRotation_BoSCAGroup.docx` | Schedule and timeline for the Lab Rotation (BoSCA Group). |
| `NCP Lab Rotation Project Evaluation WS_2026-27.docx` | Evaluation criteria for the lab rotation project. |
| `PreregistrationTemplate.docx` | Template for preregistering your study. |
| `Photo Shooting Study Data Analysis Plan.pdf` | Data analysis plan for the Photo Shooting Experiment. |
